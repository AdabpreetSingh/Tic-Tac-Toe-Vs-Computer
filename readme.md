# Tic-Tac-Toe vs Computer

A simple Tic-Tac-Toe game where you can play against the computer.

## Features

* Play Tic-Tac-Toe against the computer
* Computer makes its own moves
* Detects wins
* Displays the game result
* Restart the game and play again

## Technologies Used

* HTML
* CSS
* JavaScript

## How to Play

1. Choose a cell on the board to make your move.
2. The computer will make its move automatically.
3. The first player to get three marks in a row wins.
4. If all cells are filled without a winner, the game ends in a draw.

## How to Run

1. Clone this repository:

   ```bash
   git clone YOUR-REPOSITORY-LINK
   ```
2. Open the project folder.
3. Open `index.html` in your browser.
